# Personal Blog & Content Management System

A sleek, modern, and responsive single-page blog platform inspired by Minimal/Ghost publication designs. Built entirely with vanilla HTML5, CSS3, and JavaScript, it allows you to publish and read articles effortlessly directly in the browser without uploading external files.

## ✨ Features

- **No Backend Required**: Runs completely client-side via browser storage (`localStorage`).
- **Integrated CMS / Dashboard**: Easily write, preview, edit, and publish new articles directly from the built-in admin panel.
- **Customizable Identity**: Clean header showing your personal name instead of third-party logos.
- **Responsive & Clean UI**: Minimalist layout focused on readability across desktop, tablet, and mobile devices.
- **Dark / Light Mode**: Built-in theme switcher with smooth transitions.
- **Real-time Search**: Search through articles instantly by title, content, or tags.
- **Tag Filtering**: Filter articles dynamically by clicking on category tags.
- **Distraction-Free Reading**: Full article view with reader-friendly typography, estimated reading time, and social sharing links.
- **Interactive Comments**: Reader comment section powered by local storage.
